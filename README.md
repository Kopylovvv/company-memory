# Company Memory

«Компания, которая не забывает» — проект команды для хакатона MAX.
Сохраняем опыт из рабочих сообщений и помогаем находить подтверждённые случаи,
источники и сотрудников, которые участвовали в решении проблемы.

## Текущее состояние

Это ещё не готовый MVP. Работают FastAPI с проверкой доступности, React-страница,
которая обращается к API, API случаев (создание, исправление, подтверждение, поиск,
история оборудования) с хранением в PostgreSQL и бот MAX, который принимает текстовые
сообщения и сохраняет их черновиками случаев (`backend/app/bot/`). Сценарий диалога
бота, AI-извлечение, реальная авторизация и similarity-поиск ещё не реализованы;
текущий поиск — плоский текстовый фильтр. Контракт API для bot-only MVP принят и
описан в `contracts/README.md`.

## Быстрый запуск

Нужны Git и работающий Docker с Compose v2.

```sh
cp .env.example .env
docker compose up --build
```

- Интерфейс: http://localhost:5173
- API и документация: http://localhost:8000/docs
- Проверка процесса API: http://localhost:8000/api/health

Страница интерфейса должна показать «API доступен». Это проверяет связь frontend
с backend, но не подключение к БД, MAX или AI. Для этого стартового запуска токены
не требуются. Backend применяет миграции к PostgreSQL при старте контейнера и
хранит в ней случаи (см. `docs/architecture.md` и `backend/app/db/README.md`).

Остановка: `docker compose down`. Данные БД сохраняются в именованном томе.
`docker compose down -v` удаляет локальные данные — не используйте без необходимости.

## Структура

```text
backend/        FastAPI, будущие модули БД, бота и AI, тесты
frontend/       React + TypeScript + Vite
infra/          инструкции по будущему развёртыванию
contracts/      примеры формата данных для согласования API
data/          синтетические примеры и проверочный набор
docs/          продукт, архитектура, разработка, план, сдача
.github/        CI и шаблоны задач/pull request
compose.yaml    локальный запуск трёх сервисов
```

В репозитории не должно быть токенов, паролей или реальных корпоративных документов.
`.env.example` содержит только локальные демонстрационные настройки. Не публикуйте
эту конфигурацию в интернете: публичное развёртывание — отдельная задача.
