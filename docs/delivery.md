# MAX, развёртывание и сдача

По сообщению организаторов, которое команда получила 21 сентября, онлайн-тур
идёт с 15 по 30 сентября 2026 года. За это время нужно разработать концепцию и
создать чат-бота **или** мини-приложение. Оценка проектов проходит с 30 сентября
по 14 октября, финал — 29 октября в Казани.

По [общему FAQ организаторов](https://cloud.mail.ru/public/THoi/7pmGKgDYK),
решение сдаётся **до 30 сентября 2026 года, 12:00 МСК, в личном кабинете**.
После срока переданная версия фиксируется и не меняется. Бот должен оставаться
доступным весь период проверки. Внутренний дедлайн команды — 29 сентября:
к этому дню фиксируем рабочую версию и материалы.

FAQ подтверждает, что достаточно чат-бота без мини-приложения, а Docker для
воспроизводимого запуска обязателен. Внешние публичные документированные API
допустимы. Синтетические данные можно использовать, но их и модельные интеграции
нужно честно обозначить в README и презентации. На онлайн-этапе имя и логотип
выданного бота менять нельзя. AI-агенты допустимы как вспомогательный инструмент;
команда должна понимать и самостоятельно представлять итоговое решение.

## Уточнить у организаторов

- Какие файлы и поля потребует личный кабинет при сдаче.
- Публичность репозитория и способ доступа жюри к приватному репозиторию.
- Разрешено ли использовать ранее написанные компоненты.
- Нужно ли отдельно передавать ссылку на чат-бота и где это сделать.
- Если успеем сделать мини-приложение: когда обрабатывается форма URL и можно ли
  обновлять URL и содержимое приложения.

## Выбранный формат

Обязательный MVP — чат-бот MAX. Ввод сообщения, проверка AI-черновика,
подтверждение и поиск похожего случая должны проходить в диалоге с ботом.
Мини-приложение и форма для его URL отложены до готовности и стабилизации этого
сценария. Форма не нужна для bot-only MVP, если организаторы не сообщат обратное.

## Опциональное мини-приложение

Если останется время, frontend размещается по HTTPS и привязывается к боту MAX.
Полученный токен используется только сервером. FAQ подтверждает: ссылку
мини-приложения передают через форму ниже, а привязку к выданному боту делают
организаторы.

Форма: https://sbor-ssylok-dlya-mini-prilojeniy.testograf.ru/
Документация: https://dev.max.ru/docs/webapps/introduction
