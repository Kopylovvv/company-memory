# Data contract draft

`case.example.json` — синтетический пример для обсуждения Егора, Андрея и Макса,
не реализация API. Продуктовые endpoints ещё не утверждены.

Стабильные договорённости: ID как строки; даты ISO 8601 UTC; источник сохраняется
вместе с текстом; неизвестные факты — null; состояние черновика отдельно от фактов;
подтверждение записывает проверенного пользователя и время. Исторический случай
не доказывает причину текущей поломки.

Перед независимой разработкой утвердить схемы создания/редактирования,
подтверждения, поиска, пагинации и ошибок в OpenAPI FastAPI. Секреты и данные,
недоступные текущему пользователю, не должны попадать в ответы.
