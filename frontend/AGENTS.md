# Frontend: инструкции для AI-агентов

Сначала выполните правила из корневого `AGENTS.md`. Этот файл действует для
`frontend/`.

Frontend сейчас относится к P1. Не начинайте новые экраны, пока bot-only P0 не
проходит целиком или тимлид явно не изменит приоритет.

- Используйте React и TypeScript и опирайтесь на согласованный API-контракт.
- Не дублируйте правила подтверждения и доступа, которые должен проверять backend.
- Не помещайте токен бота, серверные ключи или другие секреты в код и переменные
  `VITE_*`: они доступны браузеру.
- Проектируйте основной путь для узкого мобильного экрана мини-приложения MAX.
- Для каждого запроса показывайте состояния загрузки, пустого ответа, ошибки,
  AI-черновика и подтверждённого случая, где они применимы.
- Фикстуры и заглушки явно помечайте; не выдавайте их за подключённый backend.
- Сохраняйте интерфейс доступным с клавиатуры и используйте понятные подписи.
- После изменения запускайте проверки из `docs/development.md` и вручную
  проходите затронутый основной сценарий.

Владелец области — Егор. Изменение API согласуйте с Андреем, а формат AI-результата
и объяснения поиска — с Максом.
