# Frontend — Егор

React + TypeScript + Vite. `src/App.tsx` пока содержит только стартовую страницу
с реальной проверкой API. Это не прототип готовых продуктовых экранов.

Первые экраны: список/поиск случаев, случай с источником и автором, история
оборудования, подтверждение и исправление черновика. Согласуйте JSON с Андреем
до подключения; временные данные явно обозначайте как демонстрационные.

Для разработки запросы `/api` идут через proxy Vite. MAX Bridge, проверка initData
на backend и размещение по HTTPS — отдельные задачи. Секреты запрещены в `VITE_*`:
такие переменные попадают в браузерную сборку.

Запуск и проверки: [development.md](../docs/development.md).
