# Инфраструктура: инструкции для AI-агентов

Сначала выполните правила из корневого `AGENTS.md`. Этот файл действует для
`infra/` и дополняет правила Александра для `.github/` и файлов запуска в корне.

- Считайте `compose.yaml` локальной средой, пока задача явно не делает её частью
  публичного развёртывания.
- Для публичного стенда документируйте TLS, домен, reverse proxy, сетевые границы,
  health checks, миграции, резервное копирование и откат.
- Не публикуйте PostgreSQL и внутренние сервисы наружу без необходимости.
- Передавайте секреты через хранилище платформы или переменные окружения; никогда
  не фиксируйте реальные значения в Git, образах, логах или workflow.
- Не удаляйте volumes и данные как часть обычной проверки.
- Закрепляйте версии и проверяйте конфигурацию на чистом окружении.
- Изменение CI должно сохранять понятные отдельные проверки backend, frontend и
  контейнерной интеграции.

Владелец области — Александр. Изменения, влияющие на запуск модулей команды,
проверяйте вместе с владельцем соответствующей области.
