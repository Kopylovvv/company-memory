# Infrastructure — Александр

`compose.yaml` предназначен для локальной разработки. Production-каркас находится
в `compose.prod.yaml`, а полный порядок подготовки VM, HTTPS, секретов, backup,
обновления и отката — в [production.md](production.md).

Текущий кандидат — VM в Yandex Cloud, но конфигурация подходит обычному Linux-
серверу у любого провайдера. Не публикуйте её до завершения #10: текущий
`X-Demo-User-Id` не является аутентификацией.
