# Infrastructure — Александр

`compose.yaml` в корне предназначен только для локальной разработки. Порты
привязаны к localhost; PostgreSQL не публикует порт на хост. Frontend использует
dev-сервер Vite. Это не конфигурация публичного сервера.

Следующая задача: production-сборка frontend, reverse proxy, HTTPS, секреты
на сервере, перезапуск сервисов, сохранение данных и ручной сценарий отката.
Сначала проверить запуск мини-приложения через выданного бота MAX.
