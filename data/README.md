# Demo and evaluation data — Макс

Только синтетические или разрешённые к использованию данные. Реальные документы
и исходные датасеты предыдущего проекта не переносим без проверки прав и правил
хакатона. Пример формата: `../contracts/case.example.json`.

Добавить небольшой набор оборудования, сотрудников и подтверждённых случаев,
а отдельно — проверочные запросы с ожидаемыми ID и примеры отсутствующего ответа.
Обязательны неполные сообщения, отрицания, неизвестное оборудование и похожие
симптомы с разными причинами. Не подгонять весь набор под один показательный запрос.
