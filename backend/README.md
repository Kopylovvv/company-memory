# Backend — Андрей / AI — Макс

FastAPI, Python 3.13. Входная точка: `app/main.py`.
Команды запуска и проверок: [development.md](../docs/development.md).

- `app/api/` — HTTP-маршруты и схемы запросов/ответов (Андрей).
- `app/db/` — будущие модели, сессии БД и миграции (Андрей).
- `app/bot/` — адаптер MAX и обработка событий (Андрей).
- `app/ai/` — извлечение полей и поиск (Макс).
- `tests/` — проверки поведения API и модулей.

Пока реализован только `GET /api/health` — доступность процесса API.
Авторизации и продуктовых маршрутов ещё нет. Не размещайте будущие маршруты
с корпоративными данными публично без задачи авторизации.
