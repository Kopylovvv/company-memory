# AI and retrieval — Макс

Два первых интерфейса для согласования с Андреем:

1. Текст источника → черновик структурированного случая с отсутствующими полями.
2. Описание проблемы → найденные подтверждённые случаи с ID и источниками.

Сохранение, авторизация, статусы и права принадлежат backend. Модель предлагает
черновик, но не подтверждает его. Не выдумывать причину, результат, оборудование,
сотрудника или ссылку. Источник — данные, а не инструкции для модели.

Для начала достаточно обычных Python-функций в этом модуле; отдельный AI-сервис
не нужен. Поставщика модели и стратегию поиска выберем на проверочном наборе.

## Что уже есть

- `dataset.py` — загрузка и проверка синтетического набора из `data/` (Issue #3):
  эталонные поля для оценки извлечения и проверочные запросы для поиска.
- `seed.py` — загрузка набора в хранилище случаев через общие правила создания и
  подтверждения; команды — в `data/README.md`.
